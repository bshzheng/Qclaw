## Schedule tracking rules

Use these rules when reviewing daily entries:

- **On track**: The task finishes on or before the planned finish date, or the next task can still start as planned.
- **At risk**: The task is not late yet, but a dependency is uncertain, labor is short, or material delivery is not confirmed.
- **Delayed**: The task misses its planned finish date or blocks the next scheduled task.
